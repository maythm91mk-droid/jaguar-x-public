# Jaguar X

ملفات عامة لتطبيق Jaguar X من OFFICE JAGUAR.

## ملف الإعدادات `config.json`

التطبيق يقرا هذا الملف كل ما ينفتح، فأي تعديل هنا يوصل لكل المشتركين بدون نسخة جديدة.

- **servers**: قائمة السيرفرات. كل سيرفر بيه:
  - `name`: الاسم اللي يشوفه المشترك (مثلاً «سيرفر 1»).
  - `admin`: اسمك الخاص للسيرفر، مشفّر.
  - `url`: عنوان السيرفر (الهوست)، مشفّر.
  الاسم الخاص والهوست يتشفّرون من «أداة سيرفرات Jaguar X»: تكتبهم بيها وتنسخ السطر الجاهز وتلصقه هنا.
  لإضافة سيرفر، الصق السطر الجاهز من الأداة وحط فارزة `,` بعد السطر اللي قبله:
  ```json
  "servers": [
    { "name": "سيرفر 1", "admin": "enc:...", "url": "enc:..." },
    { "name": "سيرفر 2", "admin": "enc:...", "url": "enc:..." }
  ],
  ```
- **support**: رقم الدعم اللي يطلع بالتطبيق.
- **message**: رسالة تطلع للمشتركين بالواجهة الرئيسية. اتركها `""` إذا ماكو رسالة.
- **latest**: آخر نسخة من التطبيق، حتى يطلع للمشترك «أكو تحديث جديد».
  - `minVersionCode`: أقل نسخة مسموحة. أي نسخة أقدم منها تطلب «لازم تحدّث» وما تشتغل لحد ما يحدّث المشترك.

> انتبه: أي فارزة ناقصة أو زايدة تخرّب الملف. إذا صار هيچ، التطبيق يكمل بآخر إعدادات صحيحة عنده وما يوكف.
